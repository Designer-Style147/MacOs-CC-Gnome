# MacOS Control Center For gnome

- This readme file is used to notify you, that before compiling the project, you need to put **SF Icon pack** into `icons` folder
- The liquid glass was copied from the [liquid-glass repo](https://github.com/ryohsuke1231/liquid-glass), thanks to the ryohsule1231 for the liquid glass effects for the gnome!

Added feature that changes your clock menu to a macOS-style format (e.g., Fri Nov 31 12:30 AM/PM). Two language formats are available—English and Spanish—which you can select in the extension's settings via the extension manager.
